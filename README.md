# Estrutura de Dados I e II - Exercícios e Projetos

Repositório dedicado ao armazenamento de exercícios e projetos desenvolvidos nas disciplinas **Estrutura de Dados I** e **Estrutura de Dados II**, do curso de Sistemas de Informação.

## 🧠 Sobre

Este repositório tem como objetivo organizar e compartilhar as práticas realizadas ao longo das disciplinas, utilizando a linguagem **C** e o ambiente **Linux**. Os conteúdos aqui presentes incluem:

- Implementações de estruturas de dados clássicas (vetores, matrizes, structs, pilhas, filas, árvores, grafos, etc.)
- Exercícios propostos em aula
- Projetos práticos avaliativos
- Provas realizadas

## 🛠️ Tecnologias e Ferramentas

- Linguagem: **C**
- Sistema operacional: **Linux**
- Compilador: `gcc`
- Editor sugerido: `Geany` ou outro de sua preferência
